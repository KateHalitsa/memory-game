# [Memory game](https://github.com/rolling-scopes-school/tasks/tree/master/tasks/memory-game) #
## Theme ##
This memory game is based on the anime *"Witch Hat Atelier"*. In this world, magic is not an innate gift but is created through the skill of drawing spells—specifically sigils with glyphs (symbols and geometric circles) rendered in special ink. While some of these spells manipulate the elements to aid people, others serve a purely decorative function.
#### Exampls:
Fire glyph:

![Regular glyph ](./src/assets/cards/Fire_sigil.png)

Decorative glyph depicting a flower:

![Regular glyph ](./src/assets/cards/Flower_Sigil.png)


However, the knowledge of how magic is cast is a closely guarded secret; to preserve it, sorcerers resort to the only spell from the realm of forbidden magic: memory erasure:

![Memory erasure ](./src/assets/decore/memory_erasure.jpg)

As you play, you attempt to memorize the glyphs, but a memory-erasing spell constantly hinders your efforts.

## Local launch instructions ##

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/) — version 24.x or higher
* npm — included with Node.js

### Installation

1. Clone the repository:

```bash
git clone https://github.com/KateHalitsa/memory-game.git
```

2. Navigate to the project directory:

```bash
cd memory-game
```

3. Install the project dependencies:

```bash
npm install
```

### Start the Development Server

Run the following command:

```bash
npm run dev
```

Vite will start the development server and display a local URL in the terminal, for example:

```text
Local: http://localhost:5173/
```

Open the displayed URL in your browser.
